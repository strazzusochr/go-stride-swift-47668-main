## Wie kann ich diesen Code bearbeiten?

Es gibt mehrere Möglichkeiten, Ihre Anwendung zu bearbeiten.

**Verwenden Sie Lovable**

Besuchen Sie einfach das [Lovable-Projekt](https://lovable.dev/projects/e927fbcf-45a6-488b-b217-900358455935) und beginnen Sie mit Ihren Anweisungen.

Änderungen, die über Lovable vorgenommen werden, werden automatisch in dieses Repository übernommen.

**Verwenden Sie Ihre bevorzugte IDE**

Wenn Sie lokal mit Ihrer eigenen IDE arbeiten möchten, können Sie dieses Repository klonen und Änderungen pushen. Geteilte Änderungen werden auch in Lovable widergespiegelt.

Die einzige Voraussetzung ist, dass Node.js & npm installiert sind - [mit nvm installieren](https://github.com/nvm-sh/nvm#installing-and-updating)

Folgen Sie diesen Schritten:

```sh
# Schritt 1: Klonen Sie das Repository über die Git-URL des Projekts.
git clone <IHRE_GIT_URL>

# Schritt 2: Navigieren Sie zum Projektverzeichnis.
cd <IHR_PROJEKTNAME>

# Schritt 3: Installieren Sie die notwendigen Abhängigkeiten.
npm i

# Schritt 4: Starten Sie den Entwicklungsserver mit automatischem Neuladen und einer sofortigen Vorschau.
npm run dev
```

**Bearbeiten Sie eine Datei direkt in GitHub**

- Navigieren Sie zur gewünschten Datei(en).
- Klicken Sie auf die Schaltfläche "Bearbeiten" (Bleistiftsymbol) oben rechts in der Dateiansicht.
- Nehmen Sie Ihre Änderungen vor und committen Sie die Änderungen.

**Verwenden Sie GitHub Codespaces**

- Navigieren Sie zur Hauptseite Ihres Repositorys.
- Klicken Sie auf die Schaltfläche "Code" (grüne Schaltfläche) oben rechts.
- Wählen Sie den Tab "Codespaces".
- Klicken Sie auf "Neuer Codespace", um eine neue Codespace-Umgebung zu starten.
- Bearbeiten Sie Dateien direkt im Codespace und committen und pushen Sie Ihre Änderungen, sobald Sie fertig sind.

Ja, das können Sie!

Um eine Domain zu verbinden, navigieren Sie zu Projekt > Einstellungen > Domains und klicken Sie auf Domain verbinden.

Lesen Sie hier mehr: [Einrichten einer benutzerdefinierten Domain](https://docs.lovable.dev/features/custom-domain#custom-domain)
